# Snowmoon · 雪月（中文译本）

Vitalik Buterin 长篇科幻小说《Snowmoon》的简体中文译本。

- **在线阅读**：https://book.routex.one
- **英文原文**：https://vitalik.eth.limo/snowmoon/
- **读者交流 / 勘误**：Telegram 群 [@SnowmoonCN](https://t.me/SnowmoonCN)，也欢迎直接提 Issue / PR

## 许可

原作 © Vitalik Buterin，以 GNU GPL v3 发布。本仓库是原作的修改版本（翻译），同样以 GPL v3 发布（见 [LICENSE](LICENSE)）。

本译本由 AI 辅助翻译，译名经统一校订，未经人工逐句审校；如与英文原文有出入，以原文为准。

## 目录结构

| 路径 | 内容 |
|---|---|
| `zh/` | 各章中文 markdown，段落与 `en/` 英文原文一一对应 |
| `extras_zh/` | 聊天记录、设备屏幕、章首地点日期等特殊块（`before` = 插在第几段之前） |
| `en/`、`src/` | 英文原文（markdown / 原网页） |
| `glossary.md` | 译名表 |
| `site/` | 生成好的静态网站 |
| `build_site.py` / `build_pdf.py` | 生成网站 / PDF |
